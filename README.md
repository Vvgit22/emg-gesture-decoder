# emg-gesture-decoder

Hand-gesture recognition from forearm and wrist EMG recorded by the open
GrabMyo dataset: a fully reproducible pipeline (download → windows → splits
→ models → ONNX) with leak-tested train/test splits and a live browser demo
on the project page.

## Install

Requires [uv](https://docs.astral.sh/uv/) and Python 3.12.

```bash
uv sync
```

## Download

```bash
make download   # mirrors ~9.1 GB into data/raw/ (resumable)
make verify     # checks every file against the dataset's SHA256SUMS manifest
```

## Reproduce

```bash
make windows          # ~7 min: builds the 537,285-window memmap
make reproduce        # features + LDA + CNN (within/cross-day) + figures
make reproduce-full   # adds cross-subject sweeps and ablations (hours)
make site             # packs artifacts/site/ for the browser demo
```

Each regenerates `artifacts/results.json`, the figures, and the ONNX
models with fixed seeds.

## Browser demo

The project page runs two exported networks in the browser on real
held-out recordings. `artifacts/site/demo.bin` is a 1.9 MB int16 bundle:
the central 2.0 s of subject 1, session 1, trial 6 — a trial that sits in
the test set of *both* models — for each of the 17 gestures. It is a tiny
extract of the public GrabMyo data (CC BY 4.0); the full raw dataset is
not redistributed here — `make download` fetches it from PhysioNet.
